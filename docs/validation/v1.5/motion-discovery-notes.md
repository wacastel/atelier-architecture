# Version 1.5 motion discovery

The first complete shared-Chicago regression retained the strict requirement that both image RMSE and temporal residual improve against matching unfiltered samples. Fourteen of fifteen cases across the Chicago destinations passed; `willis-night` failed image error while its temporal residual improved. The source/build input is preserved locally in `output/v6-review/final-input.json`; the failed report is [retained here](motion-before-correction-chicago.json). Acceptance thresholds, reference samples and benchmark camera traces were not changed.

The new lakefront alone passed all five traces. This discovery concerns unresolved distant window coverage in the expanded world, beyond the focused traffic fixtures. Final correction and verification are recorded in the release motion summary.

Repeated focused trials exposed variation between the independently built/refit raw and reconstructed renderer instances, large enough to obscure the small Willis-night difference. Matching random seeds alone did not establish identical current radiance. The revised measurement captures raw and reconstructed presentation from the same actual trace accumulation, retaining a separate high-sample reference. Earlier reports remain historical observations of their original independent-renderer method; percentages across the two measurement methods should not be treated as a controlled release-to-release comparison.

The first full Chicago run of the paired harness retained the production denoiser and still found a narrow Willis-night image-error failure while temporal error improved. Its [paired baseline report](motion-before-correction-paired-chicago.json) is preserved separately from the older independent-stream failure. Further filter decisions use the paired measurement.

A night-only spatial absolute luminance floor correction (0.03 to 0.0005, with existing variance/relative terms unchanged) then passed two complete paired five-case Chicago sequences at the same 960×600 / 32 frames / 8-SPP / 128-SPP reference settings. Willis-night image improvement was 0.0598% and 0.0606%, with temporal improvement 0.8673% and 0.8678%. The emitter-neighbor experiment remains discarded. The accepted correction is supported by paired results and a real-GPU dim-detail regression; the earlier independent-stream trials are retained as inconclusive diagnosis, not acceptance evidence. See `night-tolerance-correction.json` for exact records.
